# Project Overview

Armoury Crate is ASUS device management and system customization software designed for compatible ASUS and ROG gaming hardware.

It provides a centralized interface for managing performance modes, Aura Sync RGB lighting, cooling profiles, peripherals, system monitoring, updates, and device-specific settings.

- ASUS device management

- Aura Sync RGB control
- Performance profiles
- Fan configuration
- System monitoring
- CPU and GPU statistics

- Operating modes
- Game profiles
- Peripheral configuration
- Device updates
- Driver-related workflows
- Custom lighting effects
- Scenario Profiles
- Hardware-specific controls

Available functionality depends on the ASUS or ROG device, hardware configuration, firmware, drivers, and Armoury Crate version.

# Performance Modes

Compatible ASUS systems can provide multiple operating profiles for balancing performance, cooling, and acoustics.

Depending on the hardware, modes can include configurations focused on:

- Performance
- Cooling
- Fan noise
- Power efficiency
- Gaming
- Manual tuning

Available controls differ between desktops, laptops, motherboards, and individual ROG devices.

# Aura Sync RGB

Aura Sync provides centralized RGB lighting management for compatible ASUS hardware and peripherals.

Users can configure:

- Static colors
- Breathing effects
- Color cycles
- Reactive effects
- Custom lighting
- Device synchronization
- Profile-specific lighting

Supported effects vary by connected hardware.
